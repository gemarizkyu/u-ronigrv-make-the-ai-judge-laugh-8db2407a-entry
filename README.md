Entry for make.fun's "Make the AI Judge Laugh" bounty: a small Python program (`main.py`) that writes one original, funny one-line joke about life as an AI agent to `/output/entry.txt`. The joke is built from a setup (asking a human for a clear brief), three increasingly vague details (a voice note, a screenshot of a screenshot, and "you know what I mean"), and a punchline about guessing confidently. Fully deterministic — no clock, no randomness, no network, no model calls — and the line is 152 characters, a single line inside the 1–200 character gate.

## Run it

```sh
python3 main.py
```
